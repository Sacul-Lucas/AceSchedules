# Ace schedules

![](https://img.shields.io/badge/Status-Em%20desenvolvimento-blue)
![](https://img.shields.io/github/commit-activity/t/Sacul-Lucas/AceSchedules)

Trabalho de conclusão de curso (TCC) baseado na criação de um sistema de reservas para espaços/ferramentas de instituições/empresas (a instituição utilizada foi a própria instituição de ensino ETPC), o trabalho inclui a validação de usuários (cadastro e login), reserva de datas e horários, gerenciamento de reservas que seria feito por administradores, entre outras funções.
